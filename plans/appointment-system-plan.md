- ✅ Customizable booking flow and time slots

## 📋 System Features

### For Patients:
✅ View available time slots in real time
✅ Choose any available date and time
✅ Enter name, phone number and problem description
✅ Get immediate confirmation
✅ Get automatic reminder 2 hours before appointment
✅ Cancel or reschedule anytime

### For Doctor:
✅ Set your own working hours
✅ Block off time when you are busy
✅ See all upcoming appointments in one place
✅ Get notifications on phone and email

✅ See patient information before consultation


## 🛠️ Implementation Steps

### Step 1: Setup Cal.com Account
1.  Go to https://cal.com and sign up for free account
2.  Connect your Google Calendar / Calendar app
3.  Set your working hours and availability
4.  Create booking page for "General Consultation"

### Step 2: Configure Booking Settings
- ✅ Set appointment duration to 15 minutes
- ✅ Set minimum booking notice: 4 hours
- ✅ Set maximum booking advance: 7 days
- ✅ Enable SMS reminders
- ✅ Add custom questions:
  - Patient Name
  - Phone Number
  - Short problem description

### Step 3: Website Integration
1.  Get your public booking link from Cal.com
2.  Update the consultation button on both Landing Page and Thank You Page
3.  Button will open booking page in new tab
4.  Complete booking happens on Cal.com system
